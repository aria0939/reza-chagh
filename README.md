# رضای چاق | REZA CHAGH 🍔

> ### ▶️ [اینجا بزن و بازی کن!](https://aria0939.github.io/reza-chagh/)

بازی موبایلی HTML5 آرکید — رضا رو خوراک بده و چاقش کن!

یک بازی Casual / Arcade / Food-Eating با HTML5 Canvas، جاوااسکریپت خالص (Vanilla ES6+)، رابط کاربری کاملاً فارسی و بدون هیچ وابستگی خارجی (بدون npm، بدون CDN).

## 🕹️ نحوه بازی

- **ضربه بزن** روی هر غذای روی میز تا رضا بخوردش
- **بکش و رها کن**: غذا را به سمت دهان رضا بکش
- **دکمه «بخور»**: نزدیک‌ترین غذا را به رضا می‌دهد
- **کمبو**: خوردن سریع و پیوسته (تا ۱.۲ ثانیه فاصله) ضریب امتیاز تا **×۵** می‌دهد
- **غذای طلایی** (کمیاب): ۳ برابر امتیاز و ۲ برابر وزن
- **شکم انفجاری**: با کمبو ×۵ برای ۵ ثانیه وارد حالت ویژه شو (امتیاز ×۲، ستاره‌ها و هاله طلایی)

## 🚀 اجرای بازی

### روش ۱: سرور محلی پایتون (پیشنهادی)
```bash
cd reza-chagh
python3 -m http.server 8080
# سپس در مرورگر (ترجیحاً Chrome اندروید یا حالت موبایل دسکتاپ):
# http://localhost:8080
```

### روش ۲: Node.js
```bash
cd reza-chagh
npx serve .
```

### روش ۳: VS Code
افزونه **Live Server** را نصب کنید، روی `index.html` راست‌کلیک کنید و **Open with Live Server** را بزنید.

### روش ۴: باز کردن مستقیم فایل
فایل `index.html` را مستقیم در مرورگر باز کنید (حالت `file://` هم پشتیبانی می‌شود چون Manifest به‌صورت داخلی در کد قرار دارد).

> ⚠️ برای بهترین تجربه (خصوصاً روی موبایل) حتماً از سرور محلی یا هاست استاتیک استفاده کنید.

## 🌐 آپلود روی هاست

کل محتوای پوشه `reza-chagh` (شامل `index.html`، پوشه‌های `js`، `css`، `fonts` و `assets`) را روی هر هاست استاتیک آپلود کنید:

- **cPanel / DirectAdmin**: فایل‌ها را در پوشه `public_html` قرار دهید
- **GitHub Pages**: پوشه را در ریپوشیتوری push کنید و Pages را فعال کنید
- **Netlify / Vercel**: پوشه را drag-and-drop کنید (نیازی به build نیست)

هیچ build step یا dependency وجود ندارد؛ فایل‌ها همان‌طور که هستند اجرا می‌شوند.

## 🔧 نکات فنی

- **معماری**: Game State Manager با حالت‌های `READY / PLAYING / PAUSED / GAME_OVER` + ماشین حالت جداگانه برای شخصیت (`IDLE / EAT / CHEW / HAPPY / HUNGRY / POWERUP / FULL`)
- **انیمیشن خوردن**: برای هر ۵ مرحله وزن، مجموعه فریم مستقل (`eat_by_weight/stage_XX`) استفاده می‌شود؛ اگر وسط انیمیشن وزن تغییر کند، انیمیشن جاری با فریم‌های همان مرحله تا انتها اجرا و مرحله جدید از انیمیشن بعد اعمال می‌شود
- **مستقل از FPS**: تمام محاسبات بر پایه `dt` با سقف ۱۰۰ms (بدون پرش پس از تعویض تب)
- **توقف خودکار**: با مخفی‌شدن تب، بازی خودکار Pause می‌شود
- **ذخیره‌سازی امن**: رکورد، سکه، تنظیم صدا و لرزش در `localStorage` با try/catch
- **صدا**: ۱۳ جلوه صوتی کاملاً سنتزشده با Web Audio API (بدون فایل صوتی)؛ فعال‌سازی پس از اولین تعامل کاربر
- **دقت لمس**: شعاع لمس بزرگ‌تر از تصویر غذا (۹۶px مجازی) + حذف تأخیر ۳۰۰ms
- **DPR**: حداکثر ۲ برای تعادل کیفیت/کارایی

## 📝 محدودیت‌های شناخته‌شده

- انیمیشن‌های عمومی Happy / Hungry / Powerup پکیج، بدن مرحله صفر را نشان می‌دهند؛ برای حفظ یکپارچگی هویت بصری در همه مراحل وزن، این حالت‌ها با Tween (Bounce، لرزش، پالس) روی اسپرایت مرحله فعلی پیاده‌سازی شده‌اند تا شخصیت هنگام چاقی ناگهان لاغر نشود.
- بشقاب قرمز عمداً استفاده نمی‌شود (روی میز چاک‌دار قرمز دیده نمی‌شد).
- فایل‌های اختیاری پکیج (side-view sheet، tileset، ۱۲ spritesheet ترکیبی) بارگذاری نمی‌شوند اما در پوشه assets حفظ شده‌اند.
